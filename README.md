# 🚀 HERO.IO - Productive Apps Website

A modern, responsive web application that showcases productivity apps with clean UI, interactive features, and app management functionality.

---

## 🌐 Live Demo

👉 https://sino-cant-code.github.io/Last_PH_A3/

---

## ✨ Features

* 📱 Responsive design (mobile + desktop)
* 🔍 Search and explore apps
* 📊 App details with ratings & downloads
* ⚡ Install / Uninstall apps (local storage)
* 📈 Interactive UI with smooth navigation
* 🎯 Clean and modern UI design

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
